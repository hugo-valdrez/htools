Footwork

Calls "forward" or "backward" at random.

Each rep is a random number of forward/backward steps (within the range) followed by a beep: lunge on the beep. Set both ends equal for a fixed count.

Starts after a short countdown; Space toggles start/stop. For a smoother voice, install an "Enhanced" or "Premium" English voice in System Settings → Accessibility → Spoken Content → System Voice; it will appear in the list.
